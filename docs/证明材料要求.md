## 1. 网约车 / 出租车

| 所需材料 |
|---|
| 预约报销单 |
| 发票原件 |
| **出行行程单** |

**提醒事项**：

- 常驻地以外的行程**应与外地出差费用一并报销**
- 归属于上年度的行程费用一般不再报销（12 月份行程可在次年第一季度报销）

### 本工具的口径（2026-10 定，10-22 更正）

| 单张打车费 | 行程单 |
|---|---|
| **机场接送（接机/送机/接送/接站/送站）** | **不论金额，必须附** |
| 其他打车 **超过 200 元** | **必须附** |
| 其他打车 200 元及以下 | 可以不附 |

> 接送机不看金额，是因为它是机票那一程的地面段，本就是行程的一部分；
> 金额门槛只用来卡普通的市内/城际打车。

配置项：`config.json -> classify.taxiItineraryThreshold`（默认 200，只管非接送机）。

工具行为：

- 单张打车费 > 门槛时，在 `00_审计摘要.json` 的 `needsDocs` 里列出「缺：行程单」
- 有行程单的，**自动把行程单紧跟发票并进分类汇总 PDF**（财务要看里程明细）
- Excel「需补材料」列同步标出

## 2. 材料费

**学院通知（2026-03-01 起）**：材料费发票还需提供**自购材料清单**。

| 要求 | 说明 |
|---|---|
| 份数 | 一张发票一份，或**同一家公司合并一份** |
| 模板 | `自购模板.xlsx`，**不得改动表结构** |
| 必填 7 项 | 产品分类、商品名称、数量、包装单位、未税金额、税额、单价 |
| 文件命名 | **发票上的公司名称 + 发票金额** |

**报销办事指南（第 9 页）** 另有一条：科研材料还需办理材料出入库手续，将材料入库单（财务记账联）
或化学品与材料采购平台自购备案清单连同发票一起附上。

## 2.5 快递 / 运费（顺丰等）

快递费的发票只会写「*生产生活服务*收派服务」，看不出寄了什么。报销时要附**订单收据**。

顺丰的邮件里本来就有：真发票 PDF + 「顺丰电子发票 — 运单明细」PDF。
后者**不是发票**（没有价税合计），但**正是那份订单收据** —— 上面列着运单号、寄件时间、寄/收件地、金额，
底部还有「开票时间 / 发票号码 / 公司名称 / 发票总金额」。

工具行为：

- 不再把它当发票（也不会跟真发票撞号）
- 从它身上读出**发票号码**，按号码挂回对应发票
- 归档时命名成 `{票号}_订单收据.pdf`，摆在发票旁边
- 汇总 PDF 里**紧跟在发票后面**
- 挂不上（找不到对应发票）→ 留痕，不静默丢

### 用车行程单会自动配回来

携程的「用车行程单」是**单独一封邮件**（只有行程单、没有发票），原来的采集会把它当孤儿丢掉。
现在：

- 从行程单里抽出**订单号、用车时间、上车点、下车点、实际费用**
- 按**用车日期**挂到"需要行程单但还没拿到"的打车票上
- **同一天只有一张待补的打车票、且只有一份行程单**才挂；不唯一就不挂（挂错比不挂更难发现）
- 没用上的行程单也留痕，说明为什么没用上

> 实测（2026-10）：270.00 的成都接机（天府国际机场 T2 → 遂宁永正国际酒店，10-04 00:50）
> 与 82.00 的杭州接机（萧山国际机场 T3 → 浙大紫金港，10-05 19:07）**两张都补上了行程单**。
> 起初 82.00 因为没过 200 门槛没挂，后来更正为"接送机不论金额都要"，已补挂。

## 2.9 汇总材料里的排法

付印的材料按「一张票的材料连在一起」排：

```
发票页 → 行程单页（大额打车才要）→ 证明材料页（订单收据等）
```

每份材料都加书签，财务翻的时候能直接看目录。

## 3. 常见不予受理情形（第 10 页）

- 未盖财政部门或税务部门监制章
- 票据使用范围与内容不符
- 内容不完整（无数量、单价、金额、经济业务内容）
- 除特定区域外，未盖收款单位财务专用章
- 金额大小写不符
- 挖补、涂改、虚假
- 报销手续不齐全
- **出租车连号发票**

## 4. 差旅其他材料的通用要求（摘录）

| 场景 | 材料 |
|---|---|
| 城市间交通 | 火车票、机票**行程单**、汽车票；第三方平台购票要出票方提供电子客票行程单或税务发票 |
| 住宿 | 住宿费发票；无法取得票据时按规定包干并说明 |
| 会议/培训 | 会议、培训通知（据以报销往返伙食补助与市内交通费） |
| 野外考察 | 国内野外考察差旅费报销单 + 火车票/机票行程单/租车发票 + 住宿费发票或情况说明 |
| 因公出国（境） | 预约报销单、航空运输电子客票行程单、出国任务批件、邀请函、登机牌等 |
